# ۴Kids — Frontend (React + TypeScript)

فروشگاه آنلاین عروسک، اکسسوری مو و ست‌های هدیه — نسخه‌ی فرانت‌اند.

این پروژه در حال حاضر **فقط فرانت‌اند** است. داده‌های محصول به‌صورت موقت در کد قرار دارند
(`src/data/products.ts`) و بک‌اند (Node/Express یا Supabase) در مرحله‌ی بعد اضافه خواهد شد.

## تکنولوژی

- React 18 + TypeScript
- Vite
- React Router
- CSS Modules (بدون فریمورک UI خارجی)

## اجرای محلی

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173`) را باز کن.

## بیلد برای production

```bash
npm run build
npm run preview   # پیش‌نمایش نسخه‌ی build شده
```

## ساختار پروژه

```
frontend/
  public/
    favicon.svg
  src/
    components/     # Header, Footer, HeroCarousel, ProductCard, ...
    context/         # Cart, Wishlist, Toast (state با localStorage)
    data/            # داده‌ی موقت محصولات (products.ts)
    pages/           # Home, Shop, ProductDetail, Cart, Wishlist, 404
    types/           # تایپ‌های TypeScript
    utils/           # فرمت قیمت و اعداد فارسی
  index.html
  package.json
  vite.config.ts
  vercel.json
```

## دیپلوی روی Vercel

1. کل این ریپازیتوری (شامل پوشه‌ی `frontend`) را در GitHub آپلود کن.
2. در Vercel: **New Project → Import** همین ریپازیتوری را انتخاب کن.
3. **نکته‌ی مهم:** چون `package.json` داخل پوشه‌ی `frontend/` است نه در ریشه‌ی ریپو،
   در تنظیمات پروژه‌ی Vercel بخش **Root Directory** را روی `frontend` تنظیم کن.
   اگر این مرحله انجام نشود، بیلد با خطا مواجه می‌شود (چون Vercel در ریشه‌ی ریپو
   دنبال `package.json` می‌گردد).
4. Framework Preset باید به‌صورت خودکار **Vite** تشخیص داده شود؛
   Build Command: `npm run build`، Output Directory: `dist` (هر دو پیش‌فرض هستند).
5. Deploy را بزن.

فایل `vercel.json` داخل پروژه، ریدایرکت لازم برای مسیرهای داخلی React Router
(مثل `/product/...` یا `/shop`) را از قبل تنظیم کرده تا رفرش‌کردن صفحه با خطای ۴۰۴
مواجه نشود.

## وضعیت فعلی و نکاتی که باید بدانی

- **سبد خرید و علاقه‌مندی‌ها** در `localStorage` مرورگر ذخیره می‌شوند؛ یعنی فقط روی
  همان مرورگر/دستگاه باقی می‌مانند و بین کاربران یا دستگاه‌های مختلف synced نیستند.
  این طبیعی است چون هنوز بک‌اندی وجود ندارد.
- **تصاویر واقعی محصولات** هنوز اضافه نشده‌اند؛ به‌جای هرکدام یک پس‌زمینه‌ی رنگی
  (placeholder) نمایش داده می‌شود. هروقت عکس واقعی آماده شد، کافی‌ست مقدار
  `imageUrl` را در `src/data/products.ts` پر کنی (یا بعداً این فیلد از بک‌اند بیاید)؛
  کامپوننت `ProductMedia` به‌طور خودکار عکس واقعی را با استراتژی درست
  lazy/eager loading نمایش می‌دهد (عکس Hero و اولین محصول هر صفحه eager، بقیه lazy).
- **صفحه‌ی تسویه‌حساب (Checkout) عمداً ساخته نشده** — چون فلوی پرداخت (کارت‌به‌کارت +
  تایید دستی، طبق چیزی که مشخص کردیم) به اتصال بک‌اند نیاز دارد. ساختن یک دکمه‌ی
  Checkout که به هیچ‌جا وصل نیست/کار نمی‌کند، گمراه‌کننده بود؛ در عوض صفحه‌ی سبد خرید
  یک یادداشت کوتاه دارد که این بخش در مرحله‌ی بعد اضافه می‌شود.
- کد به‌صورت دستی نوشته شده و در محیطی بدون دسترسی به اینترنت بود، پس
  `npm install` و بیلد را خودم اجرا/تست نکرده‌ام. قبل از push کردن به GitHub،
  حتماً یک بار `npm install && npm run dev` را لوکال اجرا کن تا مطمئن شوی
  همه‌چیز درست بالا می‌آید؛ اگر خطایی دیدی برایم بفرست تا سریع درستش کنم.

## مراحل بعدی (طبق برنامه‌ای که تعیین کردیم)

- افزودن Supabase (جدول محصولات، سفارش‌ها، وضعیت سفارش)
- جایگزینی `src/data/products.ts` با فراخوانی API واقعی
- افزودن فلوی سفارش: نمایش شماره کارت برای واریز + آپلود/تایید دستی پرداخت توسط ادمین
- افزودن پنل ادمین ساده برای مدیریت محصولات و سفارش‌ها
