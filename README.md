4Kids Store

4Kids Store is a modern e-commerce web application for a kids' toy and doll store, currently under active development.

⚠️ Work in Progress: This project is not finished yet and is still under development. The current version should not be considered a representative measure of my web design and development skills, as many parts of the application are not yet implemented or finalized.

Architecture

The project is structured as a frontend-focused application with Supabase providing the backend services.

Frontend: React + TypeScript + Vite

Styling: CSS Modules

Backend & Database: Supabase + PostgreSQL

Deployment: Vercel

Version Control: Git + GitHub

Project Structure

4kids-store/ ├── frontend/ # React + TypeScript application └── supabase/ # Supabase configuration, migrations and backend services 

The frontend is deployed through Vercel, while Supabase is used for database and backend functionality. The project is being developed with a focus on a modular structure, reusable components, and a scalable architecture.
